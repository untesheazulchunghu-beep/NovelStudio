# 性能基线

本文记录 `cmd/perfprobe` 在本地 Windows 环境的首轮基线，用于后续优化前后对比。数据不是发布门槛；比较时应保持 Go 版本、操作系统、章节规模和探针参数一致。

## 环境

- 采集日期：2026-10-11
- Go：`go1.27.1`
- 系统：Windows `amd64`
- 正文：英文合成正文，另包含中文摘要命中和稀有词命中
- 调用方式：每次测量 10 次调用，表中为 P95 延迟；探针同时记录平均分配字节数，原始 JSON 未纳入表格

## 首轮结果

| 章节数 | 每章正文 | 工作区 P95 | 读取单章 P95 | 常见词搜索 P95 | 稀有词搜索 P95 | 短词命中 P95 | 短词未命中 P95 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 100 | 64 KiB | 152 µs | 209 µs | 13.3 ms | 1.23 ms | 2.07 ms | 15.0 ms |
| 500 | 64 KiB | 232 µs | 163 µs | 19.8 ms | 1.68 ms | 2.34 ms | 75.5 ms |
| 1,000 | 32 KiB | 269 µs | 104 µs | 10.3 ms | 0.71 ms | 0.97 ms | 73.8 ms |

对应命令：

```powershell
go run ./cmd/perfprobe -chapters 100 -bytes-per-chapter 65536 -iterations 10
go run ./cmd/perfprobe -chapters 500 -bytes-per-chapter 65536 -iterations 5
go run ./cmd/perfprobe -chapters 1000 -bytes-per-chapter 32768 -iterations 3
```

## 当前结论

- 工作区响应仍只返回章节摘要，响应体随章节数增长，未携带全部正文。
- 三元 FTS 搜索的稀有词查询明显低于短词兼容路径。
- 短词未命中会扫描章节正文，500 章时 P95 已达到约 75 ms；这是下一轮短词搜索优化的优先候选。
- 这组数据只适合比较趋势，不能替代真实中文长篇正文和真实磁盘环境测试。
