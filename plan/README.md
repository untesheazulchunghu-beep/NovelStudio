## 🔄 文档更新规范

### 更新时机
1. **完成迭代/里程碑**：更新进展报告、中长期规划
2. **发现新问题**：更新需要改进的内容
3. **重要设计决策**：新增 ADR
4. **调整计划**：更新下一阶段行动计划

### ADR 编写规范
- 文件名：`NNNN-标题.md`（4 位编号）
- 必需章节：状态、背景、决策、结果、后续
- 状态标记：提议、已采用、已废弃、已替代
- 参考：[决策记录/0001-模型用量与估算费用.md](./决策记录/0001-模型用量与估算费用.md)
