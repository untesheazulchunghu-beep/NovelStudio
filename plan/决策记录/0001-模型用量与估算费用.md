# 模型用量与估算费用

- 状态：采用
- 日期：2026-10-02
- 范围：M4 Provider 费率、任务 Token 记录和本机用量汇总

## 背景

OpenAI 兼容服务商并不都在流式响应中提供 Token 用量。项目需要按任务保存用量，且费用必须使用各 Provider 的实际费率口径，不能把字符估算伪装成服务商报告值。

## 决策

- 每个 Provider 保存输入、输出 USD / 百万 Token 单价。管理员手动维护价格；两项均为 0 表示没有可用费率，费用未知。只配置一侧时，另一侧按 0 单价计算。
- 请求优先启用流式 `stream_options.include_usage`。若服务商明确因该字段返回 HTTP 400，则当前调用去掉该字段重试一次。
- 服务商返回用量时记为实际用量；未返回时按提示词和输出文本长度估算，并用单独计数标明。演示模式不记 Token 用量。
- 每次调用通过 `task.usage` 事件记录提示 Token、输出 Token、费用、费率是否已配置、实际 / 估算来源及章节 / 工作流节点。任务累计列与事件在同一 SQLite 事务中更新，任务总 Token 始终等于输入 Token 与输出 Token 之和。
- 管理汇总只向本机首个注册账户开放，按任务、作品和用户聚合。其他成员仍只能查看其有权访问作品的任务用量。
- 费用按发生调用时的 Provider 费率写入任务累计，不因之后修改 Provider 价格而回算历史任务。
- 已有任务没有 Provider usage 原始数据，迁移仅初始化累计列，不推算或回填历史 Token 与费用。

## 结果

用量统计在服务商提供 Token 数时保持实际计数；缺少 usage 时仍可提供有明确标记的估算。没有配置费率时展示费用未知，避免把未知费用当作免费调用。
